# Aegys Layer

Aegys Layer is a cybersecurity project focused on detecting suspicious URLs and producing explainable risk assessments.

## Current Features

- URL risk analysis
- Suspicious keyword detection
- HTTPS verification
- Suspicious top-level domain detection
- IP-address based URL detection
- Long URL detection
- Punycode/domain spoofing detection
- Numeric risk scoring
- Human-readable threat reasons
